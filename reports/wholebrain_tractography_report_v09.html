🔬 Methodology: Whole-Brain Tractography Approach

This report presents results from our whole-brain tractography approach, which represents a significant methodological improvement over traditional ROI-to-ROI tractography.

❌ Old Approach: ROI-to-ROI

tckgen -seed_image SEED -include TARGET

  • Generates tracts FOR EACH connection
  • 5 segments × 4 targets = 20 runs per CTRL
  • SIFT2 run per-tract (loses global context)
  • Selection bias: only tracts that reach target
→

✅ New Approach: Whole-Brain + Passthrough

tckgen -seed_image MASK (1M streamlines)

  • Single unbiased whole-brain tractogram
  • SIFT2 applied ONCE globally
  • Extract passthrough tracts with tckedit -include
  • Unbiased: all possible connections represented
🎯 Key Insight: By generating 1 million streamlines across the whole brain FIRST, then applying SIFT2 globally, we get weights that reflect the TRUE fiber density across all possible pathways. Extracting passthrough tracts afterward preserves these unbiased weights.

📊 The Problem: ROI Size Bias in Connectivity Comparisons

⚠️ Critical Issue

When comparing connectivity between ROIs of different sizes, larger ROIs naturally generate more streamlines simply because they contain more seed points. This creates a bias where connectivity appears higher for larger regions, even if the actual "connection density" is the same.

In this study:

  • CTRL: Isocortex segments have ~350-1500 voxels each (total ~4000-4500 voxels per subject)
  • AP: Graft segments have ~270-1500 voxels each (total ~1000-3400 voxels per subject)
  • APTR: Graft segments have ~440-1450 voxels each (total ~2000-3600 voxels per subject)

Raw streamline counts would unfairly favor larger ROIs!

🔧 Available Solutions

Method Description Pros/Cons
1. Raw Streamline Count Count streamlines connecting ROI-A to ROI-B ❌ Only valid within-subject; heavily biased by ROI size
2. Fixed Streamline Count Generate same number of streamlines per ROI ✓ Equal sampling; ❌ Undersamples large ROIs
3. Connectivity Density Streamlines / ROI_voxels × 1000 ✓ Size-normalized; ✓ Valid cross-subject; ✓ Interpretable
4. Connection Probability Proportion of seeds that reach target ✓ Probabilistic interpretation; ❌ Loses quantitative aspect

✅ Chosen Solution: Connectivity Density

We use Connectivity Density as the primary metric:

Connectivity Density = Streamlines / Seed_Voxels × 1000

Why this approach?

  • Normalizes for ROI size: A 1000-voxel ROI and a 500-voxel ROI with equal "connection strength per voxel" will have equal density
  • Enables fair comparison: CTRL (larger atlas ROIs) and AP/APTR (smaller manual ROIs) can be fairly compared
  • Interpretable units: "Streamlines per 1000 voxels" is analogous to connection density per unit volume

📝 Methods (Manuscript-Ready)

📋 Note: This section is formatted for direct inclusion in a journal manuscript. Text can be copied and adapted as needed. All parameters and procedures are documented from the actual processing pipeline (config1.yaml).

2.1 Animals

Twelve adult mice were used in this study, divided into three experimental groups (n=4 per group): (1) CTRL – wild-type mice with normal cortical development; (2) AP (Apallial) – mice carrying the Emx1-Cre;Lhx2loxP/loxP mutation resulting in severe reduction or absence of the dorsal telencephalon without intervention; and (3) APTR (Apallial + Transplant) – mice with the same genetic mutation that received embryonic cortical tissue transplantation to restore cortical function. All procedures were conducted in accordance with institutional animal care guidelines.

2.2 MRI Acquisition

Ex vivo diffusion-weighted imaging was performed using a high-field MRI scanner. Diffusion-weighted images were acquired with the following parameters: voxel size 0.15 × 0.15 × 0.15 mm³ isotropic, 45 diffusion directions with b-values of approximately 16 and 1019 s/mm². High-resolution T2-weighted anatomical images were also acquired for registration and visualization purposes.

2.3 Image Preprocessing

2.3.1 Orientation Standardization

Raw images were reoriented to match the Allen Mouse Brain Common Coordinate Framework (CCF) orientation to enable atlas-based analysis. This involved a two-step transformation: (1) axis permutation (axes 2,1,0 for 3D volumes, 2,1,0,3 for 4D DWI) to reorder dimensions, and (2) a flip along the Y-axis (axis 1) to achieve the standard orientation.

2.3.2 DWI Preprocessing

Diffusion-weighted images underwent the following preprocessing steps using MRtrix3 (version 3.0.4; Tournier et al., 2019): (1) gradient direction verification using dwigradcheck; (2) denoising using the MP-PCA algorithm (dwidenoise; Veraart et al., 2016); (3) brain mask creation using dwi2mask; and (4) bias field correction using N4 (dwibiascorrect ants).

2.4 Fiber Orientation Distribution Estimation

Multi-tissue response functions were estimated using the dhollander algorithm (dwi2response dhollander; Dhollander et al., 2016). Fiber orientation distributions (FODs) were computed using multi-shell multi-tissue constrained spherical deconvolution (dwi2fod msmt_csd; Jeurissen et al., 2014). FOD intensity normalization was performed using mtnormalise.

2.5 Region of Interest Definition

2.5.1 CTRL Group: Atlas-Based ROIs

For CTRL subjects, regions of interest were derived from the Allen Mouse Brain CCF atlas (Wang et al., 2020). The Allen CCF template was registered to each subject using ANTs SyN nonlinear registration. ROIs were extracted for: Isocortex (seed, divided into 5 anterior-posterior segments), Thalamus, Striatum, Cerebellum, and Olfactory Cortex.

2.5.2 AP/APTR Groups: Manual ROIs

For AP and APTR subjects, ROIs were manually segmented in 3D Slicer by an expert neuroanatomist: Graft (seed, divided into 3 dorsal segments), Thalamus, Striatum, Cerebellum, and Paleocortex.

2.6 Whole-Brain Tractography

Whole-brain probabilistic tractography was performed using iFOD2 (tckgen; Tournier et al., 2010). Unlike traditional ROI-to-ROI tractography, we generated a single dense tractogram seeded throughout the entire brain mask to capture all possible white matter connections without a priori anatomical bias. One million streamlines were generated per subject with: step size 0.02 mm, maximum angle 60°, FOD cutoff 0.1, minimum length 2 mm, maximum length 15 mm.

2.7 SIFT2 Optimization

SIFT2 (Smith et al., 2015) was applied to the whole-brain tractogram to assign weights reflecting underlying fiber density. Critically, SIFT2 was applied once to the complete tractogram, allowing all pathways to compete globally for the FOD at each voxel.

2.8 Passthrough Tract Extraction

Specific anatomical connections were extracted using tckedit -include SEED -include TARGET, selecting streamlines that traversed both ROIs while preserving original SIFT2 weights.

2.9 Tract Cleaning

Extracted streamlines were cleaned using AFQ_removeFiberOutliers (Yeatman et al., 2012) to remove anatomically implausible fibers (>3 SD from the tract core).

2.10 ROI Size Normalization

To enable fair comparisons between groups with different ROI sizes, connectivity was normalized by seed ROI volume. Connectivity Density was calculated as:

Connectivity Density = (Cleaned Streamlines / Seed ROI Voxels) × 1000

This metric represents the number of streamlines per 1000 seed voxels, accounting for the substantial size differences between atlas-derived CTRL isocortex segments (~350-1500 voxels) and manually-drawn AP/APTR graft segments (~270-1500 voxels).

2.11 Statistical Analysis

Group-level statistics (mean ± SD) were calculated for connectivity density across CTRL (n=4), AP (n=4), and APTR (n=4) groups. Target-specific connectivity was analyzed by aggregating normalized values across all seed segments for each target region.
