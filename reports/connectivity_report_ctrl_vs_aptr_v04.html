⚠️ SIFT2 Methodology

SIFT2-weighted connectivity is used for all cross-subject comparisons. Per MRtrix documentation, raw streamline counts are only valid for within-subject comparisons. SIFT2 weights combined with FOD normalization (mtnormalise) enable valid between-subject comparisons by accounting for differences in FOD amplitude and tissue properties.

Connectivity Density = SIFT2_sum / ROI_voxels × 1000 (controls for ROI size bias)

Reference: MRtrix SIFT Documentation
