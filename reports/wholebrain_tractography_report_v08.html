🔬 Methodology: Why Whole-Brain Tractography?

This report presents results from our whole-brain tractography approach, which represents a significant methodological improvement over the previous ROI-to-ROI approach.

❌ Old Approach: ROI-to-ROI

tckgen -seed_image SEED -include TARGET

  • Generates tracts FOR EACH connection
  • 5 segments × 4 targets = 20 runs per CTRL
  • SIFT2 run per-tract (loses global context)
  • Selection bias: only tracts that reach target
→

✅ New Approach: Whole-Brain + Passthrough

tckgen -seed_image MASK (1M streamlines)

  • Single unbiased whole-brain tractogram
  • SIFT2 applied ONCE globally
  • Extract passthrough tracts with tckedit -include
  • Unbiased: all possible connections represented
🎯 Key Insight: By generating 1 million streamlines across the whole brain FIRST, then applying SIFT2 globally, we get weights that reflect the TRUE fiber density across all possible pathways. Extracting passthrough tracts afterward preserves these unbiased weights.

The Passthrough Extraction Method

After generating the whole-brain tractogram with SIFT2 weights, we extract specific connections using:

tckedit wholebrain_sift2.tck output.tck -include SEED_ROI -include TARGET_ROI

This keeps only streamlines that pass through BOTH the seed and target ROIs, while preserving their original SIFT2 weights from the global optimization.

📊 Understanding SIFT2 in This Context

What is SIFT2?
SIFT2 (Spherical-deconvolution Informed Filtering of Tractograms, version 2) assigns a weight to each streamline so that the weighted tractogram matches the fiber orientation distribution (FOD) at each voxel. Unlike SIFT (which removes streamlines), SIFT2 keeps all streamlines but gives them different weights.

Why Apply SIFT2 to the Whole Brain First?

The key advantage of our approach:

  1. Global optimization: SIFT2 sees ALL streamlines in the brain simultaneously, not just one pathway at a time
  2. Fair competition: Streamlines from different pathways compete for the same FOD "budget" at shared voxels (like white matter junctions)
  3. Unbiased weights: A streamline's weight reflects its contribution to the GLOBAL fiber architecture, not just one ROI-to-ROI connection
⚠️ Important: When we report "cleaned streamlines" below, these are streamlines that: (1) passed through both seed and target ROIs, (2) were cleaned with MATLAB's AFQ_removeFiberOutliers to remove anatomically implausible paths, and (3) carry SIFT2 weights from the whole-brain optimization. The counts represent high-confidence connections.

📝 Methods (Manuscript-Ready)

2.1 Animals

Twelve adult mice were used in this study, divided into three experimental groups (n=4 per group): (1) CTRL – wild-type mice with normal cortical development; (2) AP (Apallial) – mice carrying the Emx1-Cre;Lhx2loxP/loxP mutation resulting in severe reduction or absence of the dorsal telencephalon without intervention; and (3) APTR (Apallial + Transplant) – mice with the same genetic mutation that received embryonic cortical tissue transplantation to restore cortical function. All procedures were conducted in accordance with institutional animal care guidelines.

2.2 MRI Acquisition

Ex vivo diffusion-weighted imaging was performed using a high-field MRI scanner. Diffusion-weighted images were acquired with the following parameters: voxel size 0.15 × 0.15 × 0.15 mm³ isotropic, 45 diffusion directions with b-values of approximately 16 and 1019 s/mm². High-resolution T2-weighted anatomical images were also acquired for registration and visualization purposes.

2.3 Image Preprocessing

2.3.1 Orientation Standardization

Raw images were reoriented to match the Allen Mouse Brain Common Coordinate Framework (CCF) orientation to enable atlas-based analysis. This involved a two-step transformation: (1) axis permutation (axes 2,1,0 for 3D volumes, 2,1,0,3 for 4D DWI) to reorder dimensions, and (2) a flip along the Y-axis (axis 1) to achieve the standard orientation where the anterior-posterior axis runs along dimension 0 (high index = anterior), dorsal-ventral along dimension 1, and left-right along dimension 2.

2.3.2 DWI Preprocessing

Diffusion-weighted images underwent the following preprocessing steps using MRtrix3 (version 3.0.4; Tournier et al., 2019): (1) conversion to MRtrix format (.mif) with gradient table embedding; (2) gradient direction verification using dwigradcheck to ensure correct gradient orientations; (3) denoising using the MP-PCA algorithm (dwidenoise with extent 5×5×5 voxels, Exp2 estimator; Veraart et al., 2016); (4) brain mask creation using dwi2mask; and (5) bias field correction using N4 implemented in ANTs (dwibiascorrect ants with b-spline fitting distance 200, shrink factor 2).

2.3.3 DWI-to-T2w Registration

To enable accurate ROI-based tractography, the preprocessed DWI was registered to the high-resolution T2-weighted anatomical image using ANTs (Avants et al., 2011). A rigid transformation was computed using antsRegistrationSyN.sh (type 'r', 3 dimensions) with the masked mean b0 image as the moving image and the T2w as the fixed image. The resulting affine transformation matrix was converted to MRtrix format using transformconvert and applied to the full 4D DWI volume using mrtransform.

2.4 Fiber Orientation Distribution Estimation

Multi-tissue response functions were estimated using the dhollander algorithm (dwi2response dhollander; Dhollander et al., 2016), which automatically identifies single-fiber white matter (WM), gray matter (GM), and cerebrospinal fluid (CSF) voxels for response function estimation. Fiber orientation distributions (FODs) were then computed using multi-shell multi-tissue constrained spherical deconvolution (dwi2fod msmt_csd; Jeurissen et al., 2014), generating separate WM, GM, and CSF FOD images. FOD intensity normalization was performed using mtnormalise with WM and CSF compartments; the GM compartment was excluded from normalization as the tissue balance factor approached zero in mouse brain, a common occurrence due to the small GM volume in rodents (Tournier et al., 2019). The normalized WM FOD image was used for subsequent tractography.

2.5 Region of Interest Definition

2.5.1 CTRL Group: Atlas-Based ROIs

For CTRL subjects, regions of interest were derived from the Allen Mouse Brain Common Coordinate Framework (CCF) atlas (Wang et al., 2020). The Allen CCF T2 template (25 μm resolution) was registered to each subject's T2-weighted image using ANTs SyN nonlinear registration (antsRegistrationSyN.sh, type 's'). The resulting warp field was applied to the Allen annotation volume using nearest-neighbor interpolation to preserve discrete label values. ROIs were extracted by collecting all voxels belonging to the following parent structures and their hierarchical descendants: Isocortex (ID: 315; 374 child structures), Striatum (IDs: 485 dorsal + 493 ventral; 13 total structures), Thalamus (ID: 549; 74 structures), Cerebellum (ID: 512; 87 structures), and Olfactory Cortex comprising Piriform (ID: 961), Entorhinal (ID: 909), Piriform-amygdalar (ID: 788), and Postpiriform (ID: 566) areas (45 total structures). Each ROI was split into left and right hemispheres along the midline (axis 2), accounting for the negative Z-direction in the image affine.

2.5.2 AP/APTR Groups: Manual ROIs

For AP and APTR subjects, ROIs were manually segmented in 3D Slicer (version 5.x; Fedorov et al., 2012) by an expert neuroanatomist. The following regions were delineated bilaterally: Graft (the transplanted or abnormal cortical tissue), Striatum, Thalamus, Paleocortex (corresponding to the olfactory cortex in CTRL), and Cerebellum. Manual segmentations were exported as NIfTI volumes and transformed to match the standardized orientation. A correction was applied to swap left/right labels that were initially reversed during the original segmentation.

2.5.3 Seed Segmentation

The primary seed regions (Isocortex for CTRL, Graft for AP/APTR) were subdivided into anterior, central, and posterior segments along the anterior-posterior axis (axis 0 in the standardized orientation). For AP/APTR subjects, additional dorsal/ventral subdivisions were created along the dorsal-ventral axis (axis 1), resulting in 6 segments per hemisphere (anterior-dorsal, anterior-ventral, central-dorsal, central-ventral, posterior-dorsal, posterior-ventral). All ROIs and segments were resampled to FOD space using mrgrid regrid with nearest-neighbor interpolation and the WM FOD as template.

2.6 Whole-Brain Tractography

Whole-brain probabilistic tractography was performed using the iFOD2 algorithm (tckgen; Tournier et al., 2010) in MRtrix3. Unlike traditional ROI-to-ROI tractography, we generated a single dense tractogram seeded throughout the entire brain mask to capture all possible white matter connections without a priori anatomical bias. Tractography parameters were optimized for mouse brain anatomy: step size 0.02 mm (approximately 1/7 of the voxel dimension), maximum turning angle 60° per step, FOD amplitude cutoff 0.1, minimum streamline length 2 mm, and maximum streamline length 15 mm. One million streamlines were generated per subject (-select 1000000) with seeding constrained to the brain mask (-seed_image mask_flip1.mif).

2.7 SIFT2 Optimization

To obtain biologically meaningful streamline weights that reflect underlying fiber density, SIFT2 (Spherical-deconvolution Informed Filtering of Tractograms, version 2; Smith et al., 2015) was applied to the whole-brain tractogram. SIFT2 assigns a cross-sectional area multiplier to each streamline such that the weighted tractogram optimally fits the FOD in every voxel. Critically, SIFT2 was applied once to the complete 1 million streamline tractogram, allowing all pathways to compete globally for the FOD "budget" at each voxel. This approach ensures that streamline weights reflect each pathway's contribution to the brain's overall fiber architecture, rather than being optimized independently for isolated ROI pairs.

2.8 Passthrough Tract Extraction

Specific anatomical connections were extracted from the SIFT2-weighted whole-brain tractogram using a passthrough approach. For each seed-target combination, streamlines that traversed both the seed segment and target ROI were selected using tckedit -include SEED -include TARGET. This method preserves the original SIFT2 weights computed from the global optimization, providing unbiased connectivity estimates. Seed-target combinations included: seed segments (Isocortex for CTRL, Graft for AP/APTR) to Thalamus, Striatum, Cerebellum, and Olfactory/Paleocortex, with left and right hemispheres analyzed separately.

2.9 Tract Cleaning

Extracted streamlines were cleaned to remove anatomically implausible fibers using the AFQ_removeFiberOutliers function from the Automated Fiber Quantification toolbox (Yeatman et al., 2012) implemented in MATLAB R2025b. The algorithm computes a "super-fiber" representing the tract core using the mean position of all streamlines at 100 equidistant nodes. Streamlines were removed if they exceeded 3 standard deviations from the super-fiber in either Gaussian distance (spatial deviation from the tract core) or length deviation from the mean fiber length. The cleaning process was iterated up to 3 times with a 5-minute timeout per tract. Tracts with fewer than 20 streamlines were excluded from cleaning as the super-fiber computation requires sufficient samples for reliable estimation.

2.10 Statistical Analysis

For each subject, the total number of cleaned passthrough streamlines was computed by summing across all seed-target combinations. Group-level statistics (mean ± standard deviation) were calculated for CTRL (n=4), AP (n=4), and APTR (n=4) groups separately. Connectivity patterns were visualized using grouped bar charts and scatter plots with individual subject data points. Target-specific connectivity was analyzed by aggregating streamline counts across all seed segments for each target region (Thalamus, Striatum, Cerebellum, Olfactory/Paleocortex).

Image processing was performed using MRtrix3 version 3.0.4 (www.mrtrix.org; Tournier et al., 2019) and ANTs version 2.x (stnava.github.io/ANTs/; Avants et al., 2011).
